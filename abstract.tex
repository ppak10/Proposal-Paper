\begin{abstract}
Additive Manufacturing enables efficient design and fabrication workflows within
engineering, allowing for rapid iterative development of components by
circumventing the need for rigid tooling, material waste, and long development
cycles. Since its inception, this process has evolved from a quick method for
drafting design prototypes to an industrial scale process capable of achieving
high throughput and precision. Specifically, powder based processes such as
Laser Powder Bed Fusion and Selective Laser Sintering offer micrometer-level
precision for functional applications; however, present challenges in defect
mitigation and process parameter optimization. Approaches to address these
challenges have explored feedforward and feedback control of the build process
utilizing in-situ process monitoring data, multi-physics simulation, and machine
learning models to detect potential defects before they manifest in the final
part. These approaches have shown success in controlled experimental trials with
implementation of these tools yet to be done inside a continual learning enabled
agentic system. This work introduces an agentic system developed for the
optimization of process parameters and defect mitigation within the selective
laser sintering process. The system enables the intelligent automation of data
inference and tool calling orchestrated by various large language models to
search for ideal print parameters evaluated through measured tensile and
flextural properties of printed ASTM samples. Outputs and interactions are
recorded to a database enabling continual learning which further improves the
agentic system with each task. This composition of machine learning models,
physical hardware, and user driven data establishes a foundation for continual
learning enabled agentic systems in additive manufacturing.
